# E-Commerce Sales Analytics Dashboard

## Project Overview
This project focuses on analyzing e-commerce sales data using Microsoft Power BI to generate meaningful business insights through interactive dashboards.

## Objectives
- Analyze e-commerce sales performance.
- Understand sales trends and business performance.
- Present important metrics through interactive visualizations.
- Support data-driven business decisions.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Project Files
- `E-Commerce Sales Analytics.pbix` – Power BI dashboard file.
- `Nageshwari_ECommerce_Sales_Analytics_Final(power BI).pptx` – Project presentation.

## Dashboard & Analysis
The Power BI dashboard provides visual analysis of e-commerce sales data. Open the PBIX file using Power BI Desktop to explore the dashboard.
